# Project page

The [WAM-OPD project page](https://pjliu3.github.io/wam-opd-project/) presents the
paper's method, reported results and robot demonstrations.

The paper is available at [arXiv:2609.34250v1](https://arxiv.org/abs/2609.34250v1).
This code release contains the method figures used in the README; the website is
hosted separately.
